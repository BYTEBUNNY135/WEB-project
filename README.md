# PARK-O-BUDDY — Evaluation Build

## Run locally
1. Install Python 3 if it is not already installed.
2. Double-click `run.bat`, or open a terminal in this folder and run `python run.py`.
3. Open http://localhost:3000.

## Form data storage
The server creates and updates:
- `data/users.json`
- `data/bookings.json`
- `data/parking_spaces.json`

## Implemented evaluation items
- Nine linked pages (Home, About, Sign Up, Search, Results, Slot Selection, Host, Confirmation, Dashboard).
- Parker / Host / Both role selection.
- Signup validation and form submission.
- Host listing submission and live preview.
- Booking slot selection and hourly price calculation.
- Python JSON API and dashboard retrieval.

This is a classroom demonstration app. It is not a production payment or authentication system.
